# Дашборд

Одна статическая страница без сборки и внешних зависимостей: график рисуется в SVG прямо
в браузере, данные приходят из `/api/fxwatch/*`.

Развёрнутая версия: https://antonov-ai.ru/agents/fxwatch/

## Зачем он здесь

Отчёт в markdown отвечает на вопрос «всё ли работало» точнее, но читать его будет не всякий.
Дашборд решает другую задачу: показать, что сервис работает, человеку, который не станет
поднимать docker compose и не будет разбирать SQL.

Три вещи на странице стоят отдельного внимания, потому что их обычно не показывают:

* **Машина времени.** Ползунок сдвигает точку зрения в прошлое: график перерисовывается так,
  как данные были известны сервису на выбранный момент. Это прямое следствие того, что история
  хранится как последовательность наблюдений. На перезаписываемой таблице такой ползунок
  сделать было бы не из чего.

* **Отметки на графике там, где источник менял значение.** Ревизия перестаёт быть строчкой
  в журнале и становится видимой на самих данных.

* **Раздел «как это работает» простыми словами.** Половина смысла сервиса объясняется без
  единого технического термина, и это не упрощение для красоты: если процесс нельзя объяснить
  тому, кто им пользуется, его не будут использовать.

## Как запустить локально

Страница обращается к относительному пути `/api/fxwatch/`, поэтому её достаточно положить рядом
с работающим сервисом. Например, отдать через тот же nginx или любой статический сервер
с проксированием `/api/` на `localhost:8790`.

В продакшене используется первый вариант: nginx отдаёт статику и проксирует API на контейнер.
Конфигурация приведена в основном README.
